🎯 RandomHunt – A Mathematical Web Game
RandomHunt is an interactive, responsive full-stack web game designed to make practicing mathematics engaging and competitive. Built with a futuristic cyberpunk aesthetic, the game challenges players to find multiples of a randomly assigned target number within a dynamic grid under intense time pressure.

🚀 Features & Functionality
1. Dynamic Gameplay Grid: Generates a dynamic 5x5 grid filled with random numbers (1-100) at the start of each round.
2. Random Target Generation: Produces a target number (from 3 to 9) that dictates which multiples the player must locate.
3. Advanced Scoring Formula: Implements a balanced scoring system to penalize random spamming and reward precision
4. Countdown Timer: A 30-second countdown with progressive visual alerts (shifting to orange and flashing red) as time runs out.
5. Persistent Leaderboard: Integrated with a Node.js/Express backend and a PostgreSQL database to fetch and store the Top 50 high scores.
6. Immersive Cyberpunk UI: Uses stylized *Orbitron* and *Michroma* fonts, custom CSS clip-paths, linear gradient animations, and continuous video backgrounds.

🛠️ Tech Stack
1. Frontend: HTML5, CSS (Flexbox, Grid, Media Queries, Keyframe Animations), Vanilla JavaScript (ES6+).
2. Backend: Node.js, Express.js, CORS.
3. Database: PostgreSQL (`pg` pool client).
